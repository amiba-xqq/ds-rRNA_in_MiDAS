# Other sequencing related analysis

- `pepline_ATACseq.sh`: 用于进行ATAC-seq的上游分析。

- `analysis_ATACseq.sh`: 用于进行ATAC-seq的下游分析。

- `pepline_FANCD2_CUTTAG.sh`: 用于FANCD2的CUT&Tag的上游分析。

- `pepline_J2_RIPseq.sh`: 用于检测dsRNA的RIP-seq的上游分析。

- `pepline_RNAP_CUTTAG.sh`: 用于RNA聚合酶I/II/III的CUT&Tag的上游分析。

===========================================================================================

- `pepline_ATACseq.sh`: Used for upstream analysis of ATAC-seq.

- `analysis_ATACseq.sh`: Used for downstream analysis of ATAC-seq.

- `pepline_FANCD2_CUTTAG.sh`: Used for upstream CUT&Tag analysis of FANCD2.

- `pepline_J2_RIPseq.sh`: Used for upstream RIP-seq analysis to detect dsRNA.

- `pepline_RNAP_CUTTAG.sh`: Used for upstream CUT&Tag analysis of RNA polymerase I/II/III.
