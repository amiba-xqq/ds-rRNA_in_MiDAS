# WGRS related analysis

- `1.pepline_WGRS_202608.sh`: 用于进行WGRS的上游分析。

- `2.cnvkit_202608.sh`: 使用[CNVkit](https://cnvkit.readthedocs.io/en/stable/)分析得到记录了拷贝数的seq文件。

- `CNV-CDH13.ipynb`,`CNV-WWOX.ipynb`,`CNV-rDNA.ipynb`,`CNV-centromere.ipynb`: 用于seg文件可视化，观测各组在对应基因组区域的拷贝数。

- `seg.rar`: 用于jupyter notebook脚本分析的seg文件。

===========================================================================================

- `1.pipeline_WGRS_202608.sh`: Used for upstream analysis of WGRS.

- `2.cnvkit_202608.sh`: Uses [CNVkit](https://cnvkit.readthedocs.io/en/stable/) to analyze and obtain seq files recording copy numbers.

- `CNV-CDH13.ipynb`, `CNV-WWOX.ipynb`, `CNV-rDNA.ipynb`, `CNV-centromere.ipynb`: Used for visualization of seg files to observe the copy numbers of each group in the corresponding genomic regions.

- `seg.rar`: The seg files used for analysis in the Jupyter notebook scripts.
